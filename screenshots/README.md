## Recapture these before you list the product

These show the template's default branding and the seeded demo content. Replace
them with your own:

1. Run the app with demo data (`npm run setup && npm run dev`).
2. Set your name, logo and brand colour in **Admin → Settings**.
3. Sign in as `demo@agentflow.ai` for the product screens and
   `admin@agentflow.ai` for the admin panel.
4. Capture at 1600×1000 or wider — most marketplaces require at least 1200px.
5. Keep a dark-mode shot. Dark mode sells.

The automation builder, the playground's cost panel and dark mode are what set
this apart from a generic admin template — lead with those.
